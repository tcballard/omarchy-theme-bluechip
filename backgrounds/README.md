# Wallpapers

Ten 8192 × 5120 BlueChip designs. The monochrome pressed-metal design remains the default. Maximum Freedom has a matching native intro under `intros/`; the aviation extra is outside this directory in `optional/`. See `docs/wallpaper-manifest.json` for dimensions and hashes, `docs/upscale/` for enhancement provenance, and `CREDITS.md` for attribution.
